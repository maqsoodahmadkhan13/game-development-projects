## Opening a project

1. Install the Unity Editor version listed for the project.
2. In Unity Hub, choose **Add** and select that project's folder (the folder containing `Assets`, `Packages`, and `ProjectSettings`).
3. Open the project and run it from the Unity Editor.

Unity-generated folders and IDE/build outputs are excluded by the per-project `.gitignore` files. Keep project assets, package manifests, project settings, and Unity `.meta` files under version control.
